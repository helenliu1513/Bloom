# Bloom
AI-powered workplace communication coach that turns better messages into shared team growth through a collaborative virtual garden.
Bloom is a web application that makes digital collaboration feel more human. Users can paste workplace messages, choose communication goals such as Friendlier, More Collaborative, or More Diplomatic, and receive AI-improved versions that preserve intent while improving tone. Every communication improvement contributes to a shared virtual garden, encouraging healthier team culture through positive reinforcement, empathy, and collaboration. 🌱🌸
